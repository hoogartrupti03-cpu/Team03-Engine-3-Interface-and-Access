# Engine 3 – Interface and Access

## Project

Interior Design and Recommendation System

## Team

Team No: 03

## Purpose

Provides a simple, interactive, and user-friendly interface that allows users to enter their room requirements and explore suitable interior design recommendations.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Node.js
- Express.js

## Implementation

- User Login interface
- User Signup interface
- Home page and navigation
- Room selection interface
- Room dimensions input
- Interior design style selection
- Colour theme selection
- Estimated budget input
- Find My Designs button
- Design recommendation cards
- Display of matching design details
- Budget-based design filtering
- Navigation between application pages

## Main Features

- Simple and accessible user interface.
- Easy navigation between pages.
- User preference collection through forms.
- Display of interior design recommendations.
- Visual presentation of designs using images.
- Responsive and organised page layouts.

## Main Files

- `App.jsx` – Manages application navigation and page rendering.
- `Login.jsx` – Provides the user login interface.
- `Signup.jsx` – Provides the user registration interface.
- `Preferences.jsx` – Collects room details and user preferences.
- `Results.jsx` – Displays recommended interior designs.
- CSS files – Define the appearance and layout of the application.

## Expected Output

A simple and accessible interior design recommendation experience that allows users to enter their requirements and explore suitable interior designs.
